# Simple Interest Calculator

A simple Bash script that calculates simple interest based on the principal
amount, annual interest rate, and time period. This project is created as part
of the IBM Skills Network **Introduction to Git and GitHub** final project.

## Description

The calculator uses the standard simple interest formula to determine the
interest earned over a specified period.

**Formula:**

```
Simple Interest = (Principal × Rate × Time) / 100
```

## Features

- Calculates simple interest using user-provided values.
- Accepts principal amount, annual interest rate, and time period as input.
- Displays the calculated simple interest.
- Lightweight and easy to run from the command line.

## Prerequisites

- Bash shell (Linux, macOS, or Git Bash on Windows)
- Git (optional, for cloning the repository)

## Usage

1. Clone the repository:

```bash
git clone https://github.com/jahnvi-vyas/github-final-project.git
```

2. Navigate to the project directory:

```bash
cd mcino-Introduction-to-Git-and-GitHub
```

3. Make the script executable:

```bash
chmod +x simple-interest.sh
```

4. Run the script:

```bash
./simple-interest.sh
```

## Example

```
Enter the principal amount: 10000
Enter the annual interest rate: 5
Enter the time period in years: 2

Simple Interest = 1000
```

## Input

- **Principal (P)** – Initial amount
- **Rate (R)** – Annual interest rate (%)
- **Time (T)** – Time in years

## Output

- **Simple Interest = (P × R × T) / 100**
